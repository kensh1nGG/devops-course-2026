# Сравнение Git и SVN

**1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?**
В Git ветка — это просто легковесный указатель (ссылка) на конкретный коммит. Создание ветки занимает миллисекунды и не копирует файлы. В SVN ветка — это фактически полное копирование директории на центральном сервере, что требует времени и дискового пространства (исторически).

**2. Можно ли в SVN сделать коммит без интернета? Почему?**
Нет, нельзя. SVN — централизованная система. Чтобы зафиксировать изменения (сделать коммит), необходим постоянный доступ к центральному серверу. Git позволяет коммитить локально без сети.

**3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?**
SVN может быть полезен в legacy-проектах (госсектор, банки), где требуется строгий централизованный контроль доступа на уровне отдельных файлов/директорий, или в командах, где разработчики не хотят/не умеют работать с распределённой моделью и сложным слиянием веток.
