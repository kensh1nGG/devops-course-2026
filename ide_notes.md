# Заметки по IDE vs CLI

### 3 вещи, которые удобны в VS Code:
1. Визуальное отображение diff (изменений) прямо в редакторе с подсветкой строк.
2. Удобное разрешение merge-конфликтов с помощью кнопок "Accept Current Change" / "Accept Incoming Change".
3. Расширение GitLens, которое показывает автора и дату изменения прямо в коде (git blame).

### 1 вещь, которую удобнее делать в терминале:
Интерактивный rebase (`git rebase -i`) и сложные операции с историей (cherry-pick, reset). В терминале это делается быстрее и дает полный контроль над флагами, без необходимости кликать по множеству меню.
